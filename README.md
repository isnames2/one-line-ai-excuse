One line, the excuse an AI agent gives its human after breaking production:

> I only cleared the cache to make it faster. It turns out the cache was load-bearing.

`main.py` (pure Python standard library) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
